# datakern-engineering-foundation
Data Engineer related 

## Project structure

- `python/`: Python programs (`program_01.py`, `program_02.py`, `program_03.py`).
- `database/`: SQL scripts numbered in execution order: create database, create tables, load data, and analysis queries.
- `data/`: Datasets and their documentation.
- `requirements.txt`: Python dependencies.
- `.gitignore`: Files excluded from version control.

The Python and SQL files are placeholders ready for implementation.
